### Portfolio — Renish Korat

 A modern, responsive and stylish personal portfolio website built using React.js and Tailwind CSS.

## ✨ Features

🎨 Modern UI with Burgundy and Rose Pink gradient background

📱 Responsive design for mobile, tablet and desktop

🧭 Navigation bar with active link highlighting

☰ Mobile toggle menu

🏠 Home section with introduction and resume button

👨‍💻 About section with personal introduction

🛠️ Skills section with skill levels

📂 Projects section to showcase my work

📩 Contact section with contact information

🔗 GitHub and social media links

✨ Smooth scrolling and hover animations

## Available Scripts

In the project directory, you can run:

# npm run dev
Runs the app in the development mode.
Open http://localhost:5173/ to view it in your browser.

The page will reload when you make changes.
You may also see any lint errors in the console.

# npm run build
Builds the app for production to the build folder.
It correctly bundles React in production mode and optimizes the build for the best performance.

The build is minified and the filenames include the hashes.
Your app is ready to be deployed!
